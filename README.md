# Sistema de Notas v4.1 🎓

Este é um sistema simples e interativo em **C++** desenvolvido para gerenciamento, cálculo de médias e classificação de alunos em disciplinas acadêmicas. O programa possui suporte nativo para persistência de dados local, permitindo salvar os resultados gerados e visualizá-los posteriormente.

## Funcionalidades

- Cadastro de alunos e notas por disciplina
- Cálculo de médias por aluno
- Classificação: Aprovado, Recuperação ou Reprovado
- Relatório salvo em arquivo .txt com data e hora
- Leitura de relatório salvo
- Menu "Sobre o sistema"

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** C++
- **Bibliotecas Padrão:** `<iostream>`, `<string>`, `<fstream>`
- **API Específica:** `<windows.h>` (para codificação de caracteres do Console)

---

## 📂 Estrutura do Código (Evolução por Commits)

O código foi estruturado de forma incremental seguindo as boas práticas de versionamento:
1. **Commit 1:** Estrutura inicial e rotina de leitura de dados dos alunos.
2. **Commit 2:** Adicionado o módulo para inserção de notas e lógica de cálculo de médias.
3. **Commit 3:** Implementação das regras de negócio (Classificação e exibição do relatório).
4. **Commit 4:** Integração de saída de dados estruturados para arquivo físico (`ofstream`).
5. **Commit 5:** Criação do menu de entrada com suporte a leitura e renderização de relatórios pré-existentes (`ifstream`).
6. **Commit 6:** Adiciona informações sobre o sistema no menu de opções.
7. **Commit 7:** Inclui data e hora em um novo relatório
